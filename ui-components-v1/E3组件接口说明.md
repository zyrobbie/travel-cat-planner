# 日常核心体验 · 共享组件接口

本目录 `styles.css`、`tokens.json`、既有 13 张 PNG 保持冻结。`components.js` 旧演示与新页面共同导入 `daily-components.mjs`，没有复制页面专用的需求卡或回复框骨架。新增的状态布局在 `component-extensions.css` 中，旧演示不加载它。

## 新页面接入

```html
<link rel="stylesheet" href="../ui-components-v1/styles.css">
<link rel="stylesheet" href="../ui-components-v1/component-extensions.css">
```

```js
import {
  needCard, replyInput, updateReplyInputState, focusReply,
  homeNavigation, newLetterEntry, icon, escapeHtml,
  countReplyCharacters, replyInputState,
} from '../ui-components-v1/daily-components.mjs';

needCard({
  mode: 'e3', catId: 'cat-01', catName: '小咪',
  time: '今天 09:20', title: '阳光会在这里等我吗？',
  body: '完整正文，不截断，也没有展开全文。',
  replyTargetId: 'daily-reply',
  // avatarUrl / avatarAlt 可按冻结资产配置；默认采用本模块 assets。
});
replyInput({
  mode: 'e3', id: 'daily-reply', name: '小咪', value: '', maxLength: 2000,
  draftState: 'idle', submitState: 'idle', systemState: 'none', composing: false,
});
homeNavigation({active: 'cat', unread: true});
newLetterEntry({type: 'NEED_CARD', unread: true});
```

- 需求卡全文安全转义后完整显示；按钮 `data-action="focus-reply"`、`data-reply-target="daily-reply"`。事件控制器调用 `focusReply(pageRoot, button.dataset.replyTarget)` 只聚焦并滚动到本页对应文本框。
- ReplyInput 保留原 `paper / composer / label / textarea / helper / card-actions / reply-feedback` 骨架、内边距、圆角和正常字号。E3 模式无语音入口，按钮为“送出去”；发送中为“正在送出…”。
- 主导航仅“小猫”“来信盒”，操作 `home` / `inbox`，`active` 为 `cat` 或 `inbox`。新信入口类型为 `NEED_CARD` / `POSTCARD`，仅一个 `open-letter` 操作。两组件不绑定业务事件。

## 状态参数

| 参数 | 值 |
|---|---|
| `draftState` | `idle` / `saving` / `saved` / `error` / `restored` |
| `submitState` | `idle` / `submitting` / `error` / `success` |
| `systemState` | `none` / `checking` / `blocked` / `check-error` |
| `systemMessage` | 可选纯文本系统提示，不接受 HTML |
| `composing` | 原生输入合成期间为 `true`，防止未完成输入被提交 |

状态值可传同名大写形式。`saved` 必须由控制器在真实本机保存成功后传入，组件不推断保存结果；`success` 仅锁住原表单，控制器负责转到 H 页。组件不执行存储、录音、安全检查、网络或发送。

字数按可见字素计数（`Intl.Segmenter`，不支持时按 Unicode 码点退化）。2000 字可发送，2001 字保留原文并禁用。未设置会按 UTF-16 计数的 `maxlength`，不截断粘贴文字。空白内容、IME 合成中、发送中及任何非 `none` 系统状态均不可发送。

## 不重建输入框的状态更新

```js
const form = root.querySelector('[data-component="reply-input"]');
updateReplyInputState(form, {
  draftState: currentDraftState,
  submitState: currentSubmitState,
  systemState: currentSystemState,
  systemMessage: currentSystemMessage,
  composing: isComposing,
  maxLength: 2000,
});
```

此函数始终读取当前 `textarea.value`，不替换 textarea、不重写输入、不改光标选区。更新草稿本身由控制器明确赋值。自定义 `systemMessage` 和 `maxLength` 应在后续更新时继续传入。

可用 `data-slot`：`reply-input`、`reply-helper`、`reply-count`、`draft-status`、`draft-retry`、`submit-button`、`system-notice`、`system-message`、`system-retry`、`reply-feedback`。

草稿重试操作：`data-action="retry-draft"`；检查失败重试：`data-action="retry-check"`。草稿失败保留文字且允许控制器处理重试；检查失败与安全处理状态不显示发送成功。

## 200% 字号

在页面祖先设置 `data-text-scale="200"` 或 `.components-text-200`，仅共享组件文字增为 200%，保持自然换行和高度；不使用整体缩放、定高裁切或 CSS zoom。页面自己的标题、提示和外部布局由页面另行负责。
