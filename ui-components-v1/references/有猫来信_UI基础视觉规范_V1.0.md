# 有猫来信 UI 基础视觉规范 V1.0

## 1. 文档目的

本文档用于建立《有猫来信》产品 UI 的基础视觉语言。

目标：

-   将已完成的角色资产、场景资产转化为统一产品界面语言；
-   保证后续页面设计、组件设计、前端开发保持一致；
-   为 Figma、设计稿、开发实现提供基础规范。

当前基础资产：

-   4 猫角色基准板；
-   20 张场景图；
-   4 猫全身像；
-   角色轻量资产。

------------------------------------------------------------------------

# 2. 产品视觉定位

核心关键词：

-   温暖
-   陪伴
-   轻柔
-   手写感
-   小动物视角
-   成长与连接
-   小惊喜

整体感觉：

> 像一本属于用户和小猫共同写下的温暖日记。

避免：

-   工具感过强；
-   游戏化过度；
-   商业插画感；
-   复杂信息堆叠。

------------------------------------------------------------------------

# 3. 视觉语言原则

## 插画优先

UI 不应压过角色和故事。

原则：

-   图片承担情绪；
-   卡片承担信息；
-   文字承担陪伴感。

## 留白优先

保持：

-   宽松边距；
-   大面积留白；
-   低信息密度。

避免：

-   密集按钮；
-   多层卡片堆叠。

## 轻拟物但不过度

允许：

-   轻微纸张感；
-   柔和阴影；
-   手绘边缘。

避免：

-   3D 卡片；
-   强渐变；
-   强玻璃效果。

------------------------------------------------------------------------

# 4. 色彩系统

## 基础背景

方向：

-   暖白；
-   米白；
-   微黄色。

用于：

-   页面背景；
-   信件；
-   卡片。

## 主强调色

方向：

-   温暖橘色。

用于：

-   重点按钮；
-   猫咪相关状态。

## 辅助色

包括：

-   植物绿色；
-   天空蓝；
-   夜晚蓝。

分别用于：

-   成长；
-   旅行；
-   特殊情绪。

------------------------------------------------------------------------

# 5. 核心组件规范

## 日常需求卡

定位：

产品核心交互组件。

包含：

-   小猫头像；
-   来信内容；
-   时间；
-   回复入口。

视觉目标：

像小猫写来的便签。

------------------------------------------------------------------------

## 旅行明信片

定位：

产品差异化组件。

包含：

-   场景图片；
-   地点；
-   故事文字。

视觉目标：

像小猫旅行后寄回来的一张明信片。

------------------------------------------------------------------------

## 猫咪选择卡

用于：

-   初次选择；
-   确认领养。

要求：

-   全身像突出；
-   信息简单；
-   选择状态明确。

------------------------------------------------------------------------

## 回复输入组件

强调：

"和小猫说话"。

包含：

-   文字输入；
-   语音入口；
-   提交操作。

避免像普通聊天工具。

------------------------------------------------------------------------

## 成长记录卡

用于：

-   小故事；
-   旅行记录；
-   长期陪伴。

------------------------------------------------------------------------

# 6. 图片使用规范

## 场景图

用于：

-   首页氛围；
-   明信片；
-   故事页面。

原则：

不要破坏原始构图。

## 全身像

用于：

-   选猫；
-   确认页。

## 头像

用于：

-   对话；
-   列表；
-   状态展示。

------------------------------------------------------------------------

# 7. 动效原则

推荐：

-   轻微漂浮；
-   眨眼；
-   信件展开；
-   萤火虫闪烁。

避免：

-   强游戏反馈；
-   复杂粒子效果。

------------------------------------------------------------------------

# 8. MVP 页面优先级

第一批高保真页面：

1.  初遇与选猫页；
2.  首页；
3.  日常需求卡；
4.  回复页；
5.  旅行明信片页；
6.  成长记录页。

------------------------------------------------------------------------

# 9. 设计验收标准

通过标准：

-   角色、场景、UI 属于同一视觉世界；
-   用户第一眼感受到陪伴，而不是工具；
-   信息清晰但不破坏情绪；
-   规范可以被设计和开发复用。
