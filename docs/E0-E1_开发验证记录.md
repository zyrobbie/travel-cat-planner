## 可靠性与权限

- 8 次同回应并发请求只创建一次业务结果；不同内容不能用已有 key 冒充成功。
- 同一 Admin 请求 key 重复调用只发一张需求卡；action 200 后 refresh 503，界面重试继续原 key，仍只有一张。
- 用户发送 200 后读取刷新 503，保持系统确认；服务已保存但响应及结果查询失败后，改文字再发得到 409，不误报新文字已送出。
- 首次 state 503 显示可重试服务故障，不伪装成未登录邀请码页。
- 用户 B 用 A 的 letter ID 读／写都为 404；普通会话访问 Admin 为 401；非允许 Origin 写操作为 403。
- 邀请恢复为同一参与者生成新码并撤销旧用户会话；旧会话失效，重新进入后旧信仍在。
- 合成安全适配器的不可用输入返回未完成发送；拦截输入只记录独立 safety case，普通回应数不变，后续普通投递受阻。
- 安全适配器没有真实危机识别能力；此结果仅说明内部路由与数据隔离有效。
