本文件是制作与验收依据，**不代表任何页面或状态已通过验收**。下列复选框用于用户最终验收；内部制作检查已完成，详见《验收检查.md》；只有用户明确验收当前批次，才可进入下一批。

- 12 组高保真页面设计阶段规划 V1.0（随设计包提供）

- [ ] 冻结的六张组件参考图纳入对照：总览、需求卡、明信片卡、猫咪选择卡、回复输入、成长记录卡；选择页重点逐项对照猫咪选择卡。

## 4. A–C 主稿与必交状态

所有主稿按 M（390×844 CSS px）呈现；长页自然向下延伸。状态稿必须表达真实不同状态，不能只替换标题冒充状态变化。

| 页面 | 主稿文件名 | 逐项必交状态与检查 |
| --- | --- | --- |
| A 初遇与选外观 | `V1-ui-page-01A-cat-selection.png` | ☐ 初始未选择，`selectedCat=null`，继续按钮禁用；☐ 已选择一猫；☐ 图片失败且保留原卡位置与重试；☐ 从 B 返回后恢复选择 |
| B 起名 | `V1-ui-page-01B-cat-naming.png` | ☐ 空值；☐ 正常输入；☐ 输入框聚焦；☐ 12 字边界；☐ 超长错误；☐ 输入法键盘展开；☐ 从 A 返回后恢复草稿 |
| C 领养确认 | `V1-ui-page-01C-adoption-confirm.png` | ☐ 正常未确认；☐ `SUBMITTING` 提交中；☐ `ERROR` 失败可重试；☐ `UNKNOWN` 结果未知、只能读取；☐ `CONFIRMED` 已确认恢复 |

B 的“聚焦”在附件 §6.4 明确要求，虽未在 §8 汇总列表再次列出，仍属必交状态。图片失败、提交中与恢复状态不得只写在说明里。

状态稿在主稿名后加清楚的 `-state-…` 后缀，例如 `-state-selected.png`、`-state-error.png`。交付名不使用 `final`、`approved` 或日期来替代版本；不得在尚未验收时标记已定稿。

### A：可见内容与选择行为

- [ ] 标题为“选一只你喜欢的小猫吧”；四张卡按两列呈现，内部内容与冻结组件一致。
- [ ] 如采用引导语，使用“以后，它会一直是陪你生活和旅行的那一只。”；如采用本机提示，使用“当前为本机测试体验。”。
- [ ] 点击卡片只更新选择，不自动跳页；允许切换，继续按钮在已有选择时启用。
- [ ] 图片失败不替换成其他猫，不清空所选身份；原位显示失败与重试入口。
- [ ] 不增加性格测评、匹配推荐、稀有度、编号或人气比较。

### B：名字输入与草稿

- [ ] 标题“给它起个名字吧”；显示当前选中猫的正式全身像。
- [ ] 输入标签“小猫的名字”，占位文字“给它起个名字”，最多 12 个字符（正文将边界状态简称“12 字边界”）。
- [ ] 空值与超长时主按钮禁用，同时能展示对应错误/提示状态；不能因禁用按钮而让错误状态无法表达。
- [ ] 超长与空值提示清楚可见；附件建议文案分别为“名字最多 12 个字哦。”与“先给小猫起个名字吧。”，不能把建议文案误当作新增产品规则。
- [ ] 正常输入、聚焦、12 字边界、超长与键盘展开在视觉和操作上可区分；键盘不能遮住正在编辑的内容及必要操作。
- [ ] B→A→B 保留 `selectedCatId` 与 `catNameDraft`；在 A 更换猫后更新 B 的猫图，但保留名字草稿。

### C：规则与状态安全

- [ ] 标题“确认领养”；同时显示选中猫、名字、“再看看”和“确认领养”。
- [ ] 固定说明直接完整可见：**每个账号只能领养一只小猫。确认后，将无法更换或领养其他小猫。请确认你的选择。** 不折叠成链接、不弱化到难读，也不做恐吓式警告。
- [ ] 如采用本机提示，使用“当前为本机测试体验；这里演示正式版的领养规则。”；不伪造登录账号、邮箱、云端或跨设备能力。
- [ ] “再看看”返回 **A** 并保留名字草稿；确认前仍可修改外观和名字。
- [ ] `SUBMITTING` 保留猫和名字，明确显示提交中，阻止重复提交且不出现空白页。
- [ ] `ERROR` 显示“好像没有保存成功，再试一次吧。”及“再试一次”，保留原选择和名字。
- [ ] `UNKNOWN` 显示“正在确认你的小猫……”及“重新读取”；只读取既有结果，不再次创建领养。
- [ ] `CONFIRMED` 恢复已确认的同一只猫，提供“继续和它生活”；不重新开放换猫或领养表单。
- [ ] 返回、状态恢复与重试不会丢草稿、换错角色、重复创建或把已确认状态降回未确认；未确定结果不能被当作失败直接重提。
- [ ] “继续和它生活”仅表达流程出口，不借此制作第二批首页或扩展后续体验。

卡片可用宽度若与冻结组件的可读尺寸冲突，应调整页面排布或让页面变长；约 169 宽等页面参考值不能成为压缩组件内部的理由。B 猫图 M 约 200×200、S 约 160×160 为摆放建议，不是改造资产或组件的许可。
