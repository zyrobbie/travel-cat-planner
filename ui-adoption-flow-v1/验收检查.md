## 3. 实际浏览器操作

| 操作 | 本轮结果 |
| --- | --- |
| A 点击选择 | 保持 A，不自动跳页；继续才到 B |
| B 字数校验 | 12 字可用、13 字报错；emoji 按用户可见字符计数 |
| 草稿刷新与往返 | 刷新恢复输入；返回、改猫保留名字，预览跟随新猫 |
| C “再看看” | 直接回 A，选择与名字保留 |
| 提交期间刷新 | 恢复 UNKNOWN，仅提供重新读取；读到确认结果后进入 CONFIRMED |
| 已确认 | 不再开放普通换猫与起名表单 |
| ERROR | 保留猫名与输入，重试可完成 |
| 图片失败重试 | 保留对应角色，重新加载同一只猫 |

以上为实际浏览器的本机模拟验证，不代表真实服务器、账号绑定或跨设备恢复。
