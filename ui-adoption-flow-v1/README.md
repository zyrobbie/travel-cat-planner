# 有猫来信 · UI-01A–C 初遇与领养流程

**V1.0 · 待用户与团队验收。**

本目录是独立的三页设计预览，不接入正式应用的领养后台。

- [设计审阅入口](review.html#A)：查看 UI-01A、UI-01B、UI-01C、States、Responsive 与可点击的状态样例。
- [完整交互流程](index.html)：从选猫、起名到确认领养。
- [页面规范与验收说明](页面规范与验收说明.md)：页面规则、状态稿链接和验收边界。
- [素材来源与哈希](asset-manifest.json)：四猫原图和已批准组件来源。

`assets/` 含四张正式猫咪全身像，`designs/` 含 27 张检查图。原图与已批准组件文件保持原字节。审阅工具打开的 `?scene=` 样例与完整流程隔离，不读写完整流程的草稿。

完整流程使用当前标签页的 `sessionStorage` 恢复演示草稿，并在约 900ms 后给出本机模拟结果；不会创建真实账号或领养记录，也不保证跨标签、跨设备或浏览器关闭后的持久保存。`?outcome=ERROR` 与 `?outcome=UNKNOWN` 仅用于演示失败和结果未知状态。未知时只能重新读取，已确认后不能再改猫或改名。

发布前 19 组纯状态测试通过。本页面仍待用户与团队验收；部署不代表设计定稿。真机输入法、软键盘和未实测浏览器的覆盖范围以部署记录为准。
